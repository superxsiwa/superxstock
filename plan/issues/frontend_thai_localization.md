# Issue: Implement Thai Localization (รองรับภาษาไทย)

**Label:** `frontend`, `localization`, `enhancement`
**Status:** `To Do`
**Assignee:** Frontend Team

## Description
เนื่องจากผู้ใช้งานพบความยุ่งยากในการอ่านข้อมูลและเมนูที่เป็นภาษาอังกฤษทั้งหมด จึงมีความจำเป็นต้องปรับปรุงระบบให้รองรับ **"ภาษาไทย"** เป็นหลัก เพื่อเพิ่มความสะดวกในการใช้งาน (UX Improvement) 

ระบบควรสามารถเปลี่ยนข้อความที่แสดงบนหน้าจอ (UI Texts) ทั้งหมด เช่น เมนูการนำทาง, หัวตาราง, ปุ่มกด, การแจ้งเตือน (Toast Notifications) และข้อความอธิบายต่างๆ ให้เป็นภาษาไทย และตั้งค่าให้ภาษาไทยเป็นภาษาเริ่มต้น (Default Language) ของแอปพลิเคชัน

## Acceptance Criteria
- [ ] ติดตั้งไลบรารีสำหรับจัดการหลายภาษาใน React/Next.js (แนะนำ `react-i18next`)
- [ ] สร้างชุดไฟล์ภาษา (`th.json` สำหรับภาษาไทย และ `en.json` สำหรับภาษาอังกฤษเผื่อสลับกลับ) 
- [ ] แปลงข้อความที่ถูกพิมพ์ไว้ตรงๆ (Hardcoded text) ใน Components ทั้งหมดให้ใช้ระบบแปลภาษา (เช่น เปลี่ยนจาก "Portfolio" เป็น "พอร์ตโฟลิโอ" หรือ "Watchlist" เป็น "รายการเฝ้าดู")
- [ ] แปลหัวตารางข้อมูลในระบบ เช่น Price -> ราคาปัจจุบัน, Action -> คำสั่งซื้อขาย **(หมายเหตุ: ชื่อหุ้น หรือ Symbol ให้คงไว้เป็นภาษาอังกฤษเหมือนเดิม)**
- [ ] ปรับหน้าต่าง Login / Register ให้เป็นภาษาไทยทั้งหมด (เช่น "เข้าสู่ระบบ", "สมัครสมาชิก", "อีเมล", "รหัสผ่าน")
- [ ] (Optional) ทำปุ่มสำหรับสลับภาษา ไทย-อังกฤษ เผื่อให้ผู้ใช้เลือกได้ตามความถนัด
- [ ] ข้อความแจ้งเตือนข้อผิดพลาด (Error Messages) ที่ได้รับจาก Backend ควรถูกจับคู่และแสดงผลเป็นภาษาไทยให้ผู้ใช้เข้าใจง่าย

## Technical Details
- ไลบรารีที่แนะนำ: `i18next` และ `react-i18next`
- โครงสร้างโฟลเดอร์สำหรับเก็บคำแปล: `frontend/src/locales/`
